# Threat Control Matrix

| Threat | Preventive control | Detective control | Recovery test | Owning WP |
| --- | --- | --- | --- | --- |
| Untrusted repository text attempts prompt injection | Treat repository text as data inside role packets; preserve higher-priority instructions | Packet review checks for instruction-source labeling | Restore packet generation from clean fixtures | `WP-5` |
| Command configuration injects shell separators | Use argv-based command specs before external project command execution | Reject malicious separators in command fixtures | Re-run safe command fixture after rejection | `WP-6`, `WP-8` |
| Unsafe archive paths overwrite files during extraction | Reject absolute paths, traversal, and backslash paths in package validation | Zip path audit in review package verification | Extract review package to disposable directory and compare manifest | `WP-7` |
| Secrets enter generated packets or review archives | Secret redaction and path allow-list before packet/archive creation | Scan generated artifacts for configured secret patterns | Regenerate artifact after redaction fixture | `WP-5`, `WP-7` |
| State write is interrupted and leaves partial records | Write to temporary file, fsync when available, then atomic replace | Detect invalid or partial schema on next load | Simulate interrupted write and recover previous valid state | `WP-3` |
| Audit ledger is modified after the fact | Append-only event IDs and chained hashes before release candidate validation | Verify chain continuity during gate checks | Restore from last valid snapshot and replay valid events | `WP-3`, `WP-9` |
| Human decision is bypassed | Controller refuses transition when required human decision is pending | Gate check reports missing decision id | Resolve decision fixture and verify resume path | `WP-4` |
| Review package loses source identity | Bind Git commit, source manifest, manifest hash, and detached ZIP checksum | Clean extraction reproduces validate/full checks | Rebuild package from recorded commit and compare manifest | `WP-7` |
| Local workspace needs backup or restore | Store state in versioned files and avoid hidden mutable databases in v0.1 | Status command reports last valid state and audit head | Copy clean repository, run validate/full, and resume current review state | `WP-3`, `WP-9` |
| Incident handling lacks owner action | Human decision policy requires pause for external, privacy, legal, financial, and release risks | Incident finding remains OPEN until human resolution | Create structured HDR and verify task enters WAITING_HUMAN | `WP-4`, `WP-9` |
| Untrusted policy or profile contains duplicate YAML keys | WP-2 loader rejects duplicate keys before semantic evaluation | Semantic validator reports duplicate-key issue path | Duplicate-key fixture fails closed with no partial decision output | `WP-2` |
| Policy eval references unknown risk, human, skill, model-role, state, or profile IDs | WP-2 uses allow-lists from versioned policy files | Cross-file semantic validator reports unknown ID | Unknown-ID eval case returns stable fail-closed error | `WP-2` |
| Project profile attempts to lower risk or remove global gates | Merge rules allow profile risk raises but prohibit silent downgrades | Policy evaluation provenance shows global and profile source keys | Attempted-downgrade eval fails closed | `WP-2` |
| Conflicting policy overrides produce ambiguous routing | Same-priority scalar conflicts fail closed; list fields use sorted union only where specified | Deterministic replay compares canonical result bytes | Conflict fixture fails closed and replay fixture remains identical | `WP-2` |
| Malformed policy input produces partial routing output | `PolicyEvaluationResult.fail_closed=true` forbids decision output, gates, provenance, and transition authorization on rejected input | Eval suite asserts rejected inputs have `decision_emitted=false`, stable `error_code`, stable `issues`, and empty transition fields | Malformed-input fixture returns issue list with no decision output | `WP-2` |
