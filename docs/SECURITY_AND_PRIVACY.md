# Security And Privacy

ACGPS v0.1 is local and single-user. It must not include secrets, credentials, private keys, personal contact details, or production data in source files, logs, tests, review archives, or chat output.

Failure visibility is a safety requirement. Validation, review, and release gates must fail closed rather than hiding missing evidence, skipped checks, invalid schemas, or release authorization gaps.

Production release, irreversible data changes, public publishing, real communications, security policy changes, legal exposure, privacy exposure, financial exposure, and vendor-lock decisions require explicit human authorization through a structured decision record.
